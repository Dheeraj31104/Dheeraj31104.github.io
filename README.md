# Dheeraj Karanam · Portfolio

Personal portfolio website, styled as a research note. Plain HTML + CSS with inline SVG, no build step, served statically via GitHub Pages at https://dheeraj31104.github.io.

## Stack

- HTML5, CSS3, two small inline scripts (theme toggle). Works fully without JavaScript.
- Fonts self-hosted in `fonts/`: Source Serif 4, IBM Plex Sans, IBM Plex Mono (latin subsets, woff2).
- Lineage graph and the Exhibit 1 chart are inline SVG. Chart data was generated by running
  [Risk-Modeling-Portfolio-Analysis](https://github.com/Dheeraj31104/Risk-Modeling-Portfolio-Analysis)
  (GARCH(1,1) conditional VaR vs static historical VaR, 95%, 2021-03 to 2026-03).
- Light and dark themes via `prefers-color-scheme`, plus a manual toggle stored in `localStorage`.
- Hosting: GitHub Pages, user site, deployed from `main` root.

## Local preview

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## "Updated" dates

The byline and footer dates are stamped from the current month at commit time by a pre-commit hook.
Enable it once per clone:

```bash
git config core.hooksPath .githooks
```

Or run `scripts/stamp-date.sh` manually before committing.

## Deploying

Push to `main`. Pages serves the root of the branch; the site updates within a minute or two.
